\# STPL Tax Invoice Generator



An Android application developed for \*\*Sanjay Technomech Pvt. Ltd. (STPL)\*\* to simplify the creation of professional business documents.



\## 📱 About the Project



This application was developed as a practical software solution for a manufacturing/fabrication business.



The goal is to replace repetitive manual document preparation with a structured Android application that can generate professional PDF invoices using STPL's existing document format.



\## ✨ Features



\- Tax Invoice generation

\- Dynamic invoice item rows

\- Automatic calculation of taxable amounts

\- CGST + SGST support

\- IGST support

\- Automatic tax calculations

\- Automatic invoice totals

\- Amount-to-words conversion

\- PDF document generation

\- STPL-branded invoice templates

\- Customer and shipping information

\- PO and invoice details

\- Product HSN/SAC information

\- Quantity, unit and price management

\- Discount calculation

\- PDF sharing/saving through Android

\## 🏭 Real-World Application



This project was developed specifically around the workflow of a manufacturing/fabrication company.



Instead of creating a generic demonstration application, the software was designed around an actual business requirement: generating standardized tax invoices while preserving the company's existing invoice format.



\## 🧮 GST Handling



The application supports different GST scenarios:



\- \*\*CGST + SGST\*\* for applicable intra-state transactions

\- \*\*IGST\*\* for applicable inter-state transactions



Taxable values and invoice totals are calculated automatically from the entered item information.



\## 📄 PDF Generation



The application generates PDF invoices programmatically and uses STPL's document templates to maintain a consistent professional appearance.



The objective is to ensure that generated documents remain aligned with the company's existing documentation rather than introducing an unrelated invoice design.



\## 🎯 Project Goals



\- Reduce manual invoice preparation

\- Make document generation faster

\- Create a reusable digital workflow for STPL
